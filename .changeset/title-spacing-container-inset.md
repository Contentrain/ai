Two new design roles, each with the starter's own value as the default. `spacing-title` is the space under a page's or post's title (the prose h1 `margin-bottom`, default the kit's own, 0.8888889em at the base size and 0.8333333em at the large one). `container-inset` is what the `container-page` frame adds on each side when the source's wide size is a content width (default 0px, so the starter's frame is unchanged).
