CardGrid gains `layout: 'rows'`: one item per row, its title, text and link (or image) on one axis, a hairline between rows and no card box, every field of an item kept. With `index` the rows are a numbered list, each led by its number (01, 02, …) in the muted role; the list carries the order for screen readers, so the drawn number is hidden from them. The default, `grid`, draws the cards exactly as before.
