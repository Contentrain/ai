`FeatureList` items take an `iconImage`: the feature's own icon as an image file, drawn as decoration (`alt=""`) in place of the named `icon`. An icon list whose icons have no kit name (Elementor's icon list with Font Awesome's pencil-ruler, credit-card, camera) keeps its icons when it moves as a feature list. Before, the only icon field was the kit's eight names, so other icons showed as a check. The `check` style still draws one check before every feature, and an item without an image is unchanged.
