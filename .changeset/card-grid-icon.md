`CardGrid` items take an `icon`: a small image above the title, drawn as decoration (`alt=""`), the same as `Band`'s item icon. An icon box row (Elementor's icon box, a feature with its mark) keeps its icons when it moves as a card grid. Before, the card grid had no field for them, so they were not shown. A card without an icon is unchanged.
