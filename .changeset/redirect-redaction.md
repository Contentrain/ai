A conditional Redirection rule keeps its `condition` only when it is a login rule (two addresses). A cookie, header, IP, role or other condition holds the value a visitor must present, so it is no longer exported; the reason still names its type. `RawAttachment.link` is kept only when the attachment has no parent or its parent is proven public, because an attachment page under a draft, private or scheduled post carries that post's slug. Both match the Bridge (#38). The redirect parity fixture gains a cookie rule and a header rule, each without a condition.
